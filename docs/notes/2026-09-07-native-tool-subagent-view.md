# Native tool/subagent transcript view

Native sidecar rows render through the shared DSH GenericToolCard as read-only presentation. The adapter builds running or settled blocks from actual statuses only, maps declared native verbs to canonical arguments (file_path for reads), and leaves unknown names verbatim with their data. The metadata-only runtime forwards actual SDK call.name as agy.toolName at the two live announce sites, because command display titles are not tool identities. The producer retains this native name through later title-less updates; it never infers a tool from its arguments. CommandLine and command_line both map to command. No Host callbacks are passed, so paths are plain text, nothing executes, and no row becomes a durable DSH tool event.

Grouping follows actual evidence only: native runtime epoch plus validated trajectory ownership from agy.trajectory. agent-observed descriptors make zero-tool children visible; unowned pending previews stay in the approval UI until execution metadata arrives, other unowned rows stay flat, and conflicting or cyclic ancestry keeps agent containers at safe roots without guessing a parent. No child lifecycle is fabricated and no launch row links to a child: the start-subagent row keeps its own launch outcome.

Child groups render initially collapsed through the shared disclosure chrome and only inside their group; children never repeat as root rows. Display writes no usage data: ownership attaches at the activity-mapping layer and token reporting stays on the stock provider-reported seam. The usage-runtime builder offers --ownership-only (scripts/build-agy-usage-runtime.py): stock plus the trajectory patch with no Token patch.

3082 verifies three real child containers, zero-tool observation, child-only tool placement, Enter/Space disclosure, and collapsed replay after refresh. The native turn reports maximum nesting depth 1; real grandchild execution is not verified. The metadata-backed native command passes canonical Bash acceptance on 3082. The formal live suite passes three checks, and the keyless assembled replay passes six checks with a generated golden covering nested and zero-tool children. Focused lifecycle and presentation regressions cover permission-title replacement, omitted titles, command_line, and deferred unowned previews.
